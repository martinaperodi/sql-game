# SQL Mystery Game

An interactive web-based game designed for anyone who wants to learn or practice **SQL** queries in a fun, engaging way.

---

## Objective
Learn SQL fundamentals by playing detective. Analyze suspect statements, query access logs, cross-reference data, and uncover the lie to solve the case.

---

## How to Play
1. **Analyze Testimonials:** Review witness statements to reconstruct the timeline and identify suspicious activity.
2. **Execute SQL Queries:** Query the database logs to verify real movements against alibis.
3. **Solve the Case:** Catch the suspect who lied about their whereabouts and submit your accusation!
